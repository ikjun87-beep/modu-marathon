## 1) AAB 빌드

플레이스토어는 APK가 아니라 **AAB**(Android App Bundle)를 받는다.

```bash
cd app
# prebuild는 로컬 APK 스크립트와 동일하게 선행돼야 한다
npx expo prebuild --platform android --clean
cd android && ./gradlew bundleRelease
# → android/app/build/outputs/bundle/release/app-release.aab
```

⚠️ **서명키 주의.** 지금 `app/credentials/local-release.jks`로 서명하는데, 이 키를 **업로드 키**로
등록하고 **Play App Signing**(구글이 최종 서명키를 보관)을 켜는 것이 안전하다. Play App Signing
없이 이 키가 최종 서명키가 되면, **키를 잃는 순간 앱 업데이트가 영원히 불가능**해진다.
`local-release.jks`는 gitignore돼 있으므로 별도 백업이 필수다.

## 3) 데이터 안전 양식 — 답변 초안

우리가 실제로 하는 일 그대로 적는다(거짓 신고는 앱 삭제 사유).

| 항목 | 수집? | 내용 |
|---|---|---|
| **위치(정확한 위치)** | 수집 O · 전송 **X** | GPS는 **온디바이스에서 거리 계산에만** 쓰고 원시 좌표는 서버에 저장하지 않는다(`run-path.ts` — 경로는 이 기기에만). 서버(`runs`)엔 거리·시간·페이스만 올라간다 |
| **건강·피트니스** | 수집 O · 전송 O | 러닝 거리·시간·페이스, 평균 심박(워치 연동 시). 심박은 **별도 동의**(`health-consent.ts`) |
| **개인 식별정보** | 수집 O · 전송 O | 러너 네임(사용자가 정하는 별명), 이메일(선택 로그인 시) |
| **사진** | 수집 O · 전송 O | 크루 갤러리에 올린 사진만. 프로필 사진은 **기기 로컬 저장**(서버 미전송) |
| **암호화 전송** | O | Firebase HTTPS |
| **삭제 요청 경로** | O | 앱 내에서 본인 기록·사진 삭제 가능 |

## 4) 권한 정당화 (심사에서 물어본다)

- `ACCESS_BACKGROUND_LOCATION` — **러닝 앱의 핵심 기능**: 화면을 끄거나 다른 앱을 봐도 경로가
  끊기지 않아야 한다. 심사 제출 시 이 설명 + 시연 영상이 요구될 수 있다.
  ⚠️ 지금은 실제로 백그라운드 추적을 구현하지 않았다(“화면을 켜 둔 채로 달려주세요” 안내 중).
  **구현 전이라면 이 권한을 매니페스트에서 빼는 편이 심사가 쉽다.**
- `health.READ_*`(Health Connect) — 갤럭시워치 러닝 불러오기. Health Connect 정책상 별도 선언 필요.
