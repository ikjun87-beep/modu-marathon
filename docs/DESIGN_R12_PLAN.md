## 0. 왜 부분 수정으로는 안 되는가

R10에서 규칙 위반 28건을 고쳤는데도 독립 채점은 **79점**이었습니다. 감점의 무게중심을 보면 이유가 분명합니다.

| 축 | 점수 | 성격 |
|---|---|---|
| 브랜드 일관성 | 18/20 | ✅ 규칙은 잡혔다 |
| 타이포·정보위계 | 13/15 | ✅ 대체로 잡혔다 |
| 컴포넌트 체계 | 17/20 | ✅ 대체로 잡혔다 |
| 색·대비 | 12/15 | △ |
| **레이아웃·여백** | **11/15** | ❌ |
| **감성·차별성(AI스럽지 않은가)** | **8/15** | ❌❌ |

**규칙 준수 축은 이미 90% 근처고, 구조 축이 60~73%입니다.** 즉 남은 21점은 "규칙을 더 잘 지켜서" 얻을 수 없습니다. 구조를 바꿔야 합니다.

### "AI스럽다"의 확정된 원인 3가지

1. **단일 카드 템플릿의 완전 복사** — 흰 라운드 카드 + 원형 소프트블루 아이콘 + 제목/부제. 5개 탭 전부 같은 틀에 텍스트만 다릅니다. 화면이 바뀌어도 "새 화면"이 아니라 "같은 템플릿"으로 읽힙니다.
2. **시그니처가 두 번째 템플릿이 됐다** — `CLAUDE.md`는 "탭당 1곳은 카드 문법을 깨는 시그니처"를 요구했는데, 다크 네이비 카드가 **홈·러닝 두 탭 최상단에 같은 톤·같은 위치·같은 구성**으로 반복됩니다. 예외가 아니라 규칙이 하나 더 늘었을 뿐입니다.
3. **팔레트 단조로움** — 블루+화이트+그레이가 전부, 골드는 극소량. **원형 파스텔 아이콘 + 라운드 카드 + 단일 브랜드 컬러는 v0/Bolt류 AI 스캐폴딩의 가장 흔한 문법입니다.**

### 경쟁 분석이 준 결정적 단서

상위 앱은 성취를 **"저장 가능한 시각 자산"** 으로 축적시킵니다 — Strava 히트맵·경로, NRC 배지·스트릭, 런데이 레벨 색, 삼성헬스 링·금속 뱃지. **우리는 성취를 숫자로만 보여줍니다.** 숫자는 카드에 담기고, 카드는 반복되고, 반복은 AI스러움이 됩니다.

그리고 뼈아픈 사실 — **처방은 이미 우리 문서에 적혀 있었습니다.** `DESIGN.md`의 "앱 디자인 큐(M3~M4에서 구현)" 절:

> 공유 카드(최고 ROI) / 크루 피드 카드 + **👏 박수** + **지도 썸네일** / 페이스+고도 결합 차트 / 축하 모멘트 / 다크 모드

**전부 미구현입니다.** (축하 모멘트만 배지 콘페티로 일부 구현) 이번 개편은 새 발명이 아니라 **밀린 숙제를 하는 것**입니다.

## 1. 개편 원칙 — "탭마다 다른 레이아웃 언어"

카드를 더 예쁘게 만드는 게 아니라, **탭마다 지배적 레이아웃을 다르게** 가져갑니다. 그래야 탭을 옮길 때 "다른 곳에 왔다"가 읽힙니다.

| 탭 | 지금 | 바꿀 레이아웃 언어 | 근거 |
|---|---|---|---|
| 홈 | 카드 스택 | **타임라인(오늘의 활동)** | 크루가 핵심인데 "지금 살아있음"이 안 보임(격차8) |
| 크루 | 카드 스택 | **사진 우선 그리드** | 친목 앱의 자산은 사진. 갤러리를 조연→주연으로 |
| 러닝 | 카드 스택 | **지도 썸네일 리스트** | 성취의 1급 증거(Strava·NRC). `run-map`은 이미 있음 |
| 랭킹 | 카드 스택 + 1위 시그니처 | **유지** — 여기만 다크 시그니처 독점 | 이미 유일하게 성공한 예외 |
| 마이 | 카드 스택 | **프로필 히어로 + 배지 그리드** | 성장 서사의 집. 마스코트를 크게 |

**다크 네이비 카드는 랭킹 탭 1위 카드에만 남깁니다.** 홈·러닝의 다크 히어로는 다른 형태로 교체합니다(아래 2-1, 2-3).

## 2. 탭별 설계

### 2-1. 홈 — 타임라인
- 상단: 인사 + 마스코트(유지, 이미 좋음)
- **다크 히어로 카드 제거** → 오늘 거리는 타임라인 첫 줄에 인라인으로
- **오늘의 활동 타임라인**: 세로 라인 + 시각 노드. `runs`·`attendance`·`guestbook`을 시간순 병합
  - `오늘 6:20 · 쭌쭌님이 5.2km 뛰었어요 [👏]`
  - `어제 · 8월 2일 모임에 2명이 참석 예정`
  - 비어 있으면 → `오늘은 아직 조용해요. 첫 러닝을 남겨볼까요?` + 마스코트
- 하단 빈 공간 문제(79점 감점 사유) 자연 해소 — 타임라인은 데이터만큼 길어짐
- **CTA 위계 교정**: `러닝 시작`을 풀폭 강조, `워치 불러오기`는 아이콘+텍스트 링크로 낮춤(격차5)

### 2-2. 크루 — 사진 우선
- 갤러리를 **화면 상단**으로. 2열 그리드, 사진에 러너 이름·거리 오버레이
- 사진 카드에 **👏 박수** (Strava Kudos의 따뜻한 대안 — `DESIGN.md` 기획대로)
- 모임·방명록은 그 아래로
- 러너 네임 입력 옆에 **캐릭터 선택** 노출(격차10)

### 2-3. 러닝 — 지도 썸네일 리스트
- 행 왼쪽의 원형 아이콘 뱃지(AI스러움의 주범) → **경로 미니맵 썸네일**로 교체
  - GPS 기록: `run-path.ts`의 저장 경로로 미니맵
  - 워치·직접입력(경로 없음): 마스코트 실루엣 or 거리 숫자 타일
- 다크 히어로 → **가로 스트립**(오늘/이번주/누적 3분할, 배경 없이 구분선만)

### 2-4. 랭킹 — 유지 + 규칙 교정
- 1위 다크 시그니처 유지(유일한 예외로 격상)
- **1위 카드 단위 `km` 골드 → 블루** (R11 중대 지적: 옆 리포트 카드는 블루라 규칙이 갈림)
- 진행바 트랙/채움 명도차 강화(R11 지적)

### 2-5. 마이 — 프로필 히어로
- 상단에 **마스코트 대형 + 러너 네임 + 레벨** 히어로(카드 아님, 배경 톤)
- **커스텀 프로필 사진** 지원(5장 참조)
- 배지 그리드: 획득/미획득 시각 강도 차등(R11 지적 — 지금은 5장이 전부 같은 회색)

## 3. 색 — 단조로움 해소 (규칙은 유지)

블루+골드 2색 규율은 **더 엄격히** 지킵니다(NRC의 2색 혼용 실패가 반면교사). 단조로움은 **색을 늘리지 않고** 해소합니다.

1. **표면 단계 추가**: `bg` / `card` / `tint`(브랜드 4% 틴트) / `dark` — 탭 헤더에 미세한 톤차를 줘 탭마다 공기가 달라짐
2. **아바타 링에 팀색**: 마스코트 레드/그린 팀색을 아바타 테두리에 사용 → **사람마다 색이 달라짐** = 화면에 자연스러운 색 다양성. 브랜드색을 안 건드리고 색을 얻는 방법
3. **진행바 대비 강화**: 트랙 `warm` → `line2`, 채움은 골드 유지

## 4. `5키로` 리브랜딩

- **앱 이름**: `모두의 마라톤` → **`5키로`** (당근·삼쩜삼식 친숙어)
- **표기**: `5키로`로 통일(`오키로` 아님 — 숫자가 브랜드 자산이고 Black Han Sans와도 맞음)
- **슬로건**: `오늘 5키로, 오키?` (후보: `5키로면 충분해` / `가볍게, 같이, 5키로`)
- **적용 범위**: `app.json` name·스플래시·마이 탭 하단 버전 표기·온보딩 첫 화면
- **카피 톤 재점검**(토스 시사점 — 이름은 쉬운데 화면이 어려우면 부조화):
  - 전문 용어 최소화, 해요체·긍정형
  - **영문 eyebrow(`RUNNING`/`CREW`/`RANKING`) 제거 검토** — 카드 반복 감소에도 기여하고 "쉬운 이름"과도 정합
- ⚠️ **런처 아이콘·워드마크는 이번 범위에서 제외** (별도 라운드) — 이름·카피·스플래시까지만

## 5. 커스텀 프로필 사진

- 갤러리 base64 업로드 방식 재사용(`gallery-section.tsx` 검증된 경로)
- **아바타 = 내 사진 or 마스코트 4종** 선택. 링 색은 팀색(3-2와 연동)
- 저장 위치: 이름과 함께 공유 스키마에 — 크루·랭킹·댓글 어디서나 같은 얼굴이 보여야 함
- **온보딩으로 당김**(격차10) — 첫 30초에 "내 것으로 만들었다"는 소유감
- ⚠️ 개인정보: 얼굴 사진은 민감할 수 있음 → **선택 사항**으로 두고 기본은 마스코트

## 7. 하지 않을 것 (경쟁 분석 결론)

- Strava식 세그먼트·크라운 경쟁 → 친목 크루엔 위협적

- 잦은 IA 개편 → Strava의 실증된 안티패턴
